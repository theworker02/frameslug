# frameslug

Frame and reshape slug text streams with deterministic transforms.

**Site:** https://theworker02.github.io/frameslug/

## Install / run

```bash
git clone https://github.com/theworker02/frameslug.git
cd frameslug
node src/cli.js
node --test
```
